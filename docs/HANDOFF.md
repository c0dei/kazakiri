## 設定ダイアログの作り直し（コミット前の作業。実機で順に確認してもらっている最中）

- **保存ボタン方式**: 操作は「下書き」（部品の状態）を変えるだけ。**保存**（Enter も）を押したときに `apply_all` がアプリと settings.ini へ反映する。押しても閉じず、ボタンの左に「✓ 保存しました」を 2.5 秒出し、メインのステータスバーにも出す。変更したまま閉じる（閉じる・Esc・×・「キー割り当て」を開く）と、`confirm_unsaved` が確認を出す。`DIRTY` は入力欄の EN_CHANGE などで立ち、`sync()` で下ろす。
- **スクロール**: ページの内容が表示領域（タイトルの下〜ボタンの行の上）より長いときは、ホイール／Tab で移ったとき（`ensure_visible`）にスクロールする。部品は `relayout` でスクロール量だけずらして置き、`clip_to_view`（`SetWindowRgn`）でボタンの行・タイトルにかぶらないよう切り取る。カードは `paint_bg` で表示領域に切り取って描く。ページの高さは `Ctrls.page_h`（`create` で計算。**説明文の STATIC を足したら、`notes` の配列も直す**）。
- **自前描画は最小限**: スイッチ・切り替え（システム／ライト／ダーク）・色の見本だけ。フォント名の欄、− ＋ ボタン、保存・閉じるなどは標準の部品（Fluent 風に自前で描く案は、手間に合わないので取りやめた）。標準ボタンは、`WM_CTLCOLORBTN` で背景をダイアログの地の色で塗らないと、角に白い下地が出る（スイッチなどの透明ボタンだけ NULL ブラシ）。
- **フォントは「入力欄 + 選択... + − 14 ＋」**: 「選択...」は Windows 標準のフォント選択ウィンドウ（`pick_font`、`ChooseFontW`）。選んだ名前と大きさは欄に入るだけで、反映は「保存」のとき。コンボボックスは、位置・大きさを変えるたびに全選択になるので、やめた。
- **IME の設定は廃止**（常にエディタ内に描く）。`ime_inline` は設定ファイル・メニュー・設定画面から消した。
- **メインウィンドウのスクロールバー**: タイトルバー・ツールバー・ステータスバーは全幅（`full_w`）、縦スクロールバーは本文の領域の右端だけ、横スクロールバーは本文の下端（結果パネル・ステータスバーの上）。`client_size()` は縦スクロールバーの幅だけ引き、高さは引かない（`text_height` が横スクロールバーの高さ `hbar_h` を引く）。本文の外（スクロールバーの列・行）では、カーソルは矢印。
- 見た目の確認は `PrintWindow` で自分のウィンドウだけを撮る（設定ダイアログは、WM_COMMAND 115 を投函して開き、クラス名 `KazakiriSettingsDialog` で探す）。**ほかの exe が起動中だと、起動した 2 つ目が引き継いで終わる**ので、確認の前に、ユーザーのアプリを閉じてもらう。
